# Privacy

PocketDesk sends keyboard, pointer, and media input only to the Bluetooth host you select. It does not include an account, analytics service, advertising SDK, or remote server.

The app stores preferences such as the selected appearance, sensitivities, host type, and last selected Bluetooth device on the phone. Diagnostic entries are stored locally and may include Bluetooth device names, addresses, connection states, and error messages. They are not uploaded automatically. Review a log before using the in-app share action.

Android Bluetooth permissions are used to register the phone as a HID keyboard and mouse and to connect to a paired host. Notification permission is used for the connection status while the input service is running.
